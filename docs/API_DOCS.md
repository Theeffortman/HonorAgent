# API Reference

Base URL (local): `http://localhost:8000`. Interactive docs generated by FastAPI are at `/docs` and `/openapi.json`.

No authentication is enforced by the server. All data is held in memory and cleared on restart.

## Response envelope

All `/api/v1` endpoints return:

```json
{
  "success": true,
  "data": {},
  "message": "操作成功",
  "request_id": "req_ab12cd34ef56"
}
```

Errors use FastAPI's default format, e.g. `{"detail": "Task not found"}`, with status 400 or 404 (or the GitHub status code for a failed GitHub request). Invalid request bodies return 422.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | Health check, returns `{"status": "ok", "service": "honor-agent"}` (no envelope) |
| GET | `/` | Static web UI |
| POST | `/api/v1/tasks` | Create a task (201) |
| GET | `/api/v1/tasks` | List all tasks |
| GET | `/api/v1/tasks/{task_id}` | Get one task |
| POST | `/api/v1/tasks/{task_id}/run` | Run the task's agents and return the result |
| GET | `/api/v1/tasks/{task_id}/result` | Get the stored result |
| GET | `/api/v1/tasks/{task_id}/evolution` | Get the stored scoring report |
| GET | `/api/v1/agents` | List the 3 registered agents |
| POST | `/api/v1/github/analyze` | Analyze a GitHub repository |

### POST /api/v1/tasks

```json
{
  "name": "Weekly sales summary",
  "description": "optional",
  "agents": ["data_analyst", "report_generator"],
  "params": {"data_source": "sales.csv", "date_range": "2026-W40", "extra": {}},
  "priority": "normal"
}
```

- `name` is required. `priority` is one of `low`, `normal`, `high`, `critical`.
- `params` may also be any free-form object.
- Returns the task with `id` (`task_<12 hex>`), `status: "created"`, `created_at`, `updated_at`.

### POST /api/v1/tasks/{task_id}/run

Runs synchronously and returns:

```json
{
  "task_id": "task_...",
  "status": "completed",
  "output": {
    "task_id": "task_...",
    "status": "completed",
    "strategy": "sequential",
    "agent_count": 2,
    "runs": [{"agent_id": "data_analyst", "agent_name": "Data Analyst", "status": "completed",
              "input_summary": "...", "output": {"summary": "...", "findings": [], "handoff": "..."},
              "started_at": "...", "completed_at": "..."}],
    "final_output": {"summary": "...", "agent_sequence": [], "handoffs": [], "latest_output": {}},
    "evolution": {"...": "see below"},
    "started_at": "...",
    "completed_at": "..."
  }
}
```

Unknown agent IDs appear as runs with `status: "skipped"`.

### GET /api/v1/tasks/{task_id}/evolution

```json
{
  "task_id": "task_...",
  "overall_score": 100,
  "readiness": "strong",
  "strengths": [],
  "risks": [],
  "recommended_next_actions": [],
  "agent_reports": [{"agent_id": "data_analyst", "score": 100, "strengths": [], "risks": [], "improvement_actions": []}],
  "generated_at": "..."
}
```

Scores are rule-based; see [ARCHITECTURE.md](ARCHITECTURE.md).

### GET /api/v1/agents

Returns `id`, `name`, `description` and `capabilities` for `data_analyst`, `report_generator` and `github_intelligence`.

### POST /api/v1/github/analyze

```json
{"url": "https://github.com/owner/repo", "include_remote": true}
```

Returns `owner`, `repo`, `url`, `health_score`, `signals`, `risks`, `suggested_tasks` and `metadata`. With `include_remote: false`, or if GitHub cannot be reached, scoring uses the URL only. An invalid URL returns 400. Set `GITHUB_TOKEN` in the server environment for private repos or higher rate limits.

## Python client

```python
import asyncio
from honor_agent.client import HonorAgent

async def main():
    client = HonorAgent(api_key="dev-api-key", base_url="http://localhost:8000")
    task = await client.tasks.create(name="Demo", agents=["data_analyst", "report_generator"])
    result = await client.tasks.run(task.id)
    report = await client.tasks.evolution(task.id)
    print(result.status, report.overall_score)

asyncio.run(main())
```

Available methods: `tasks.create/get/list/run/result/evolution`, `agents.list`, `github.analyze`.
